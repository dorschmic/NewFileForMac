04 — Features

Klein im Menü.
Groß im Alltag.

Deine Vorlagen.

Leg eine Datei in den Vorlagen-Ordner – beim nächsten Rechtsklick steht sie im Menü. Die Zahl vorne bestimmt nur die Reihenfolge.

10 Textdokument.txt→ Textdokument
20 Markdown.md→ Markdown
15 Notiz.md→ Notiz
90 Word-Dokument.docx→ Word-Dokument

~/Library/Application Support/NewFileForMac/Templates

Nie überschreiben.

Name schon vergeben? Dann wird nummeriert – auch wenn zwei Aufträge gleichzeitig laufen.

  • Neue Datei.txt
  • Neue Datei 2.txt
  • Neue Datei 3.txt

Echte Office-Dateien.

Leere .docx, .xlsx und .pptx sind gültige Pakete – keine 0-Byte-Attrappen, die Word nicht öffnet.

[Content_Types].xml_rels/.relsword/document.xml

Mehrfachauswahl.

Zehn Videos markiert? Das Menü zeigt nur Formate, die für alle passen – und arbeitet sie nacheinander ab.

.mp4.mov.mkv→ MP3 · M4A · GIF · …

Sagt Bescheid.

Eine Mitteilung, sobald alles fertig ist. Ein Klick darauf zeigt die neuen Dateien im Finder.

In MP3 konvertiert3 Dateien

Regeln als JSON.

Jede Konvertierung ist eine Zeile Konfiguration: Eingabe-Endungen, Ziel, Werkzeug, Argumente. Eigene Regeln haben Vorrang und überleben jedes Update.

{ "inputs": ["md"],
  "outputs": [
    { "ext": "pdf", "label": "PDF",
      "group": "Dokument", "via": "html" }
  ] }

Ketten & Fallbacks.

Markdown → HTML → PDF in einem Klick. Ist LibreOffice installiert, wird es genutzt – sonst springt das eingebaute Werkzeug ein.

MD→HTML→PDF

Sandbox inklusive.

Die Finder-Erweiterung läuft in der Sandbox und baut nur das Menü. Die Arbeit macht eine kleine Menüleisten-App.

Finder→Extension→App

Überall im Finder.

Im Kontextmenü, auf leerem Hintergrund, in der Seitenleiste und als Button in der Symbolleiste.
